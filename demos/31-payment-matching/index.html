    実際のお仕事では

    毎月の入金の確認を、表計算の中で進められるようにします。合わないものだけを人が見る形にして、確かめる行を減らすための見本です。

    • 入金の CSV を取り込む

      • ネットバンキングから用意した入金の CSV を Googleスプレッドシート（GAS）か Excel に取り込み、設定した時刻に照合できます
      • 名義の全角・半角や空白の揺れも、決まりを決めてそろえられます

    • 合わないものだけ人が見る

      • 要確認の行だけを一覧にします
      • 受託制作では、名義が分からない入金から、取引先の別の名義を登録する画面を追加できます

    • 期日を過ぎた請求のご連絡

      • 受託制作では、期日を過ぎた請求の取引先ごとに、お知らせの文面の下書きを作る機能を追加できます
      • 送るのはお店の方です

    お店で決めていただくこと

    • 振込手数料の差額をどこまで認めるか（取引先ごと）
    • 取引先の別の名義の登録
    • 差額の会計の扱い（税理士の方とご相談ください）

    銀行の API や会計ソフトとのつなぎは、使える条件と費用を確かめてから決めます（内容によりお見積もり）。
