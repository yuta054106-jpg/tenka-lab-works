衛生管理の記録表（お店の人の画面）

冷蔵庫の温度と衛生のチェックを、
スマホで毎日の記録に

開店前と閉店後の冷蔵庫・冷凍庫の温度と、毎日の衛生のチェックを、スマホで記録します。基準を外れるとその場で「基準外」と出て、とった対応を残せます。月の記録表には記録漏れの日に印が付き、そのまま A4 横向けに印刷できます。

  1. 1今日の温度とチェックを記録する
  2. 2月の記録表で漏れと否を見る
  3. 3温度の最高・最低・平均を振り返る
  4. 4CSV・印刷で保管する
  • ※ デモ（架空のお店）です。記録はすべて架空です。実在のお店の記録やお名前は入力しないでください。
  • ※ これは記録の仕組みの見本です。項目（一般的衛生管理7・重要管理3）・温度の基準・1日2回の測定は、この架空のお店の設定です。実際の項目と基準は、お店の衛生管理計画と保健所の指導に従ってください。
  • ※ このデモは、1日分（開店前・閉店後の温度とチェック）をまとめて入れて「記録する」で確定する見本です。途中の保存はしません。
  • ※ このデモの「今日」は 2026年12月1日 に決めてあります（日付が変わっても同じ結果になるように）。見本は 2026年11月の記録です（定休日は月曜）。
  • ※ 記録はお使いのブラウザの中にだけ保存します（この端末・このブラウザだけ）。どこにも送信しません。対応のひとことも、この端末に保存され、CSV と印刷に出ます。「見本に戻す」で元に戻せます。
  • ※ この端末では保存できないため、記録はこのページを開いている間だけ残ります（再読み込みすると見本に戻ります）。
  • ※ 保存されていた記録が読めなかったため、見本の記録に戻しました。

          月の記録表を印刷（A4 横）
          
            
          保管用の月次記録表の見本として、選んでいる月の記録表と、否・基準外の対応を A4 横向けにまとめます。記録の量や印刷の設定で2枚以上になることがあります。PDF にするには、印刷の画面で送信先を「PDF に保存」にします。
          
            
            
          印刷の向きは「横」を選んでください。
          
          
          
        
          
      
          
    
          

    
          
      
    
          

    
          
      
          実際のお仕事では
          
      
          いまお使いのチェック表と、お店の衛生管理計画（手引書をもとに作ったもの）を見せていただき、項目・基準・冷蔵庫の台数をそのまま合わせて作ります。
          
      
          
        
          
          
          
          毎日の記録をスプレッドシートに
          
          
            
            
          • 記録するたびに、Google スプレッドシートに1行ずつためる形にできます（Google Apps Script など）
            • 
          
          
        
          
        
          
          
          
          記録漏れ・基準外を店長に
          
          
            
            
          • 閉店の時刻を過ぎても記録が無い日や、基準外が出た時に、店長に知らせる形にできます。知らせる時点（測った時か、1日分を確定した時か）と手段は、お見積もりの時に決めます
            • 
          
          
        
          
        
          
          
          
          月末にまとめて印刷・保管
          
          
            
            
          • 月が替わったら、前月分の記録表を A4 で印刷できる形にまとめ、保管しやすくします
            • 
          
          
        
          
      
          
      
          費用は、つなぐ先と機能によって変わるため、別にお見積もりします。
          
      
          衛生管理の基準そのもの（項目・温度・頻度）の判断はしません。お店の衛生管理計画と保健所の指導に合わせて作ります。保健所への提出の代行もしません。
